PREPARE FOR VIVA QUESTIONS
--------------------------
Q: Why use object-oriented programming?
A: Classes split responsibilities: users, complaint categories, file storage,
   authentication and UI. Inheritance/interfaces support reusable behavior.
Q: Give inheritance examples.
A: Complaint extends User; room extends Complaint; Plumber extends Washroom.
Q: What is an interface example?
A: worker is implemented by room and Washroom.
Q: Where is complaint data stored?
A: In individual .properties files in the local complaints directory.
Q: Can everyone log in as admin?
A: The app checks admin login separately, but this is a demonstration and
   not production-grade security because credentials are in source code.
Q: Can students change status?
A: No status-edit controls are offered in the student dashboard. Admin has
   these controls. This is application UI role separation, not a secure server.
Q: Can it run on other computers?
A: Yes if Java is installed and the project folder is copied, but data does
   not automatically synchronize between computers.
